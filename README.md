# Giftora — Premium Home Page

This package contains ONLY the Giftora home page.

## Files
- `index.html` — Home page
- `style.css` — Premium responsive styling
- `script.js` — Navbar, mobile menu, scroll reveal, wishlist, toast and newsletter interactions

## Future navigation
The navbar and occasion cards are already linked to:
- birthday.html
- marriage.html
- anniversary.html
- puberty.html
- valentines.html

Those pages are intentionally NOT included because this package is only the Home Page.

## Run
Open `index.html` in a modern browser.

Images use remote Unsplash URLs, so an internet connection is needed for the image assets.
